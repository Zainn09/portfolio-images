- **98 Vintage Art Garage** (<https://vintageartgarage.com>) — The live storefront is password-protected and publishes only a branded temporary-closure page ("Vintage Art Garage is temporarily closed while we’re traveling. We’ll reopen in late October."). Every storefront route redirects to /password, the DNS-declared Shopify origin reports "This store will be right back / Store unavailable", and the sitemap and products.json endpoints return no storefront data. No authentic storefront UI states are retrievable, and the criteria exclude password/closed-state screenshots, cached pages, and fabricated material.

## Capture standards

- Desktop coverage: 1440 × 900
- Mobile coverage: 390 × 844
- Video: 1280 × 720 MP4, short task-oriented walkthrough
- No checkout completion, purchases, account creation, or personal data entry
- No fabricated defects, pages, products, testimonials, features, or interactions
- Exact and perceptual near-duplicate rejection
- Publicly unavailable routes are documented in the relevant project README

Each project folder contains an image inventory, video notes, availability notes, and descriptive filenames.
